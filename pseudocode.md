## Descriptive Steps to Analyze a Data Set

### 1: Loading the Data Set
  * Import data set into environment
  * Visually glance through columns names and observe data types
  
### 2: Clean the Data
  * Check for missing and incomplete values; determine how to handle these
  * Remove duplicate rows if appropriate
  * Verify columns have correct data types (auto-detected usually)
  * Scan for incorrect entries or rows and eliminate if appropriate

### 3: Calculate Summary Statistics
  * For numeric variables, calculate mean, median, mode, min, max, standard deviation, or generate a histogram to determine the distribution 
  * For categorical variables calculate count by category or percentage of the whole.
  
### 4: Create Visualizations
  * Use relevant chart and plots for the type of variables
  * Box plots, scatter plots, and time series are all good examples of visualizations
  * Use color and legends to add flavor to your charts and to highlight certain interactions
  * Label axes and clearly title the plot, include subtitles if more explanations are needed
  
### 5: Interpret Results
  * Review summary statistics and charts to identify interest trends or general observations
  * If there's a specific question being posed, focus your interpretation on that and possibly related findings
  * Acknowledge any concerns or limitations you find in your analysis
