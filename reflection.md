## Reflection

I learned quite a bit from the readings this week. I had some general knowledge and exposure to GitHub
from my undergraduate studies as well as from my professional career but I had never actually used the software.
The readings definitely help clarify what terms like "push", "pull", and "commit" meant.  I had vague understandings of the terminology
but to finally learn the true definitions and see them in action was very helpful. The single biggest learning moment for me 
so far has definitely been the GitHub desktop to online connection. I never really understood why it couldn't just be all
cloud-based but I see that with some of the coding softwares you need that local file connect that GitHub Desktop offers.

I haven't had any major tech issues so far. I was a bit confused about why the online version of GitHub could view
and access all of the folders/files in the repository while my desktop version was essentially "empty".  I did review some
of the additional documentation on the GitHub website to see that this is completely normal and that things would appear
to commit once I made some changes and sure enough that worked.

I can certainly see GitHub helping future team projects by allowing multiple people to work on files at one time. 
I really like the Google Sheets analogy provided in our reading. That reference was obviously simple but it clicked with me.
Amidst all the hustle and bustle of everyone contributing, GitHub provides crucial metadata and a sequential history of 
changes that tell a story about the creation of all the work. This improves overall visibility while also
providing context behind additions that help current and future analysts alike.
